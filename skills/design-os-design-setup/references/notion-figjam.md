The workspace without a Figma design file. Read at step 4 when the person wants no Figma file, the Figma MCP server isn't available, or the work is mostly copy, flow or operations rather than layout.

## Notion workspace

One page (or the Designer handoff page itself, extended), created as a private draft unless the person names a parent:

- **Start here** callout: what the work is, links to brief, Linear item and map card, what changed since any prior design.
- **Screens table:** one row per board (ID, screen and state, change: Fix/Compose/Extend, owner and sign-off, current reference link, prior design link, status). This replaces the Figma groups.
- **Per group, a toggle** with keep / change / drop bullets and links. These carry what stickies would.
- **Open questions** as to-dos, each naming who answers it.
- **Still to gather:** each missing reference with its link and who to ask.

## FigJam board

Good for flow-first work, or when the team reviews in FigJam. FigJam has real stickies.

- One section per group, in flow order, with arrows for the journey.
- In each section: stickies (same kinds and colours as `figma.md`), a text block with links, and placeholders for screenshots the designer should drop in.
- Use the Figma `generate_diagram` tool for the flow skeleton, then `use_figma` in the board for stickies and sections.

Either way, link the workspace from the handoff page as the primary place to work.

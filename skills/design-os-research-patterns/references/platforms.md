# Platform tiers

Select the 12-15 most relevant per run. Clarity is issuer-facing, so weight the issuer tier for admin, cap table, document, and approval screens. Weight marketplaces for transaction and order screens.

## Issuer / equity management (closest to Clarity's jobs)
- Carta
- Pulley
- Ledgy
- Shareworks (Morgan Stanley)
- Global Shares (J.P. Morgan)
- Astrella

## Secondary marketplaces
- Nasdaq Private Market
- Forge
- EquityZen
- Augment
- Caplight

Note: marketplaces rarely document logged-in UI publicly. Expect gaps; lean on specialists.

## Adjacent B2B finance and ops
- Mercury
- Ramp
- Brex
- Stripe Dashboard
- Rippling
- DocuSign
- Wealthsimple (consumer; use for order review and confirmation patterns)

## Out-of-industry favorites
- Linear (status, workflow states)
- Shopify Admin (dense admin tables, bulk actions)
- Vercel (dashboards, activity feeds)
- Notion (permissions, sharing)
- Airtable (flexible table views)

## Specialists (pick per feature; examples)
- Data rooms / document sharing: DocSend, Datasite, Ansarada, Intralinks, Papermark, Dealroom.net
- Signing: DocuSign, Dropbox Sign
- Payments / payouts: Stripe, Wise
- Approvals / spend: Ramp, Brex, Airbase
- Onboarding / KYC: Persona, Plaid
- Notifications / inbox: Linear, GitHub

## Wildcard ideas (pick 3-5 per run by pattern)
- Multi-step flows: Airbnb checkout, TurboTax
- Permissions and sharing: Google Drive, Figma, Box, Dropbox
- Empty states and onboarding: Notion, Linear
- Data-heavy tables: Retool, Attio, Datadog
- Audit and history: GitHub, Google Docs version history
